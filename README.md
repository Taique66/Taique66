### [Homelab de infraestrutura](https://github.com/Taique66/homelab-infrastructure)

Laboratório local com **CachyOS, KVM/QEMU, Ubuntu Server e Windows 11**, com documentação e evidências dos testes.

- Criação de máquinas virtuais e testes de comunicação na rede NAT do libvirt.
- Acesso ao Ubuntu por SSH com chave Ed25519.
- Instalação do Nginx, publicação de uma página local e leitura de logs HTTP.
- Simulação de interrupção do serviço e validação da recuperação.
